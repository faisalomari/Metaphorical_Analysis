Executive summary

Do examples help? Bottom line: few-shot examples help Gemini unambiguously, help Claude for 2 of 3 example sets, and do not help — or actively hurt — GPT-5.4-mini. A single blanket "yes, few-shot helps" conclusion would be wrong for this subtype/prompt/model combination; the effect is model-dependent.

How much does the choice of examples matter? So example-choice sensitivity is real but concentrated: it's not "any two example sets differ," it's specifically "Set C differs from A and B" — and that gap is large enough to be a bigger factor than whether few-shot is used at all, for 2 of the 3 models (Claude, GPT). example_sets.json confirms Set C's two example verses are both built on the same root ع-ق-ل (التعقيل) applied to different objects, with no other pattern represented — the leading candidate explanation this pilot was designed to test, and the data here is consistent with (not proof of) that homogeneity hurting generalization for Claude and GPT. Gemini's relative insensitivity to the same C-set homogeneity is itself a notable, model-dependent finding, not something assumed in advance.

Model comparison: Cost-adjusted: Gemini's advantage with few-shot, combined with being ~3x cheaper than Claude and only slightly pricier than GPT, makes it the standout choice for this subtype if few-shot examples are used — Claude's much higher cost ($7.09 of the $10.57 total) is not matched by a corresponding performance edge over Gemini anywhere in this table.

5. Plain answer

No — this data does not show that Abu-Nuwas-sourced examples help more on Abu Nuwas poems than on other poets' poems.

  • Across all 3 models × 2 criteria × 3 example sets (18 comparisons), the gain-over-Z for the Abu Nuwas group is not significantly different from the gain-over-Z for the other-poets group in 17 of 18 cases — the 95% CIs on the difference are wide and straddle zero.
  • The one significant case (Claude, set C, strict and token) goes in the opposite direction: set C hurt Abu Nuwas poems' F1 significantly *more* than it hurt other poems' F1, not less — and this is driven heavily by a single poem (9078) collapsing to F1=0 for 2 of 3 models at set C, not a broad same-poet pattern.
  • The confound check (§2) rules out "Abu Nuwas poems are just inherently easier, so any boost looks bigger" as a confound in a consistent direction — Abu Nuwas is *harder* than average at zero-shot for Claude and GPT, easier only for Gemini, and GT density is only mildly higher (+14%) for Abu Nuwas, not enough to explain swings of the size seen in §4.

Why this should be read as "no detectable effect," not "proven absent": the Abu Nuwas group is only 5 poems, every cell is 1 run (no noise baseline per CLAUDE.md rule 2), and §4 shows single-poem swings of 0.1–0.3 F1 are common at this poem count — individual poems, not a same-poet effect, are doing most of the moving. The bootstrap CIs in §3 are correspondingly wide (often spanning ±0.15–0.35 F1), i.e. too wide to rule out a real but modest same-poet effect either. This check is indicative only and should not be treated as a settled finding; a same-poet effect, if real, would need a substantially larger Abu Nuwas sample (and ideally a 2nd run per cell) to detect reliably.
