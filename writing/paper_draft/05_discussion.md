# Discussion

## A difficulty pattern, not a difficulty scale

The frozen test-set results answer RQ1 and RQ2 together, and the answer is not simply that some elements are harder than others. Simile, whose own definition names an explicit comparative particle as its defining feature, reaches strict-criterion F1 of 0.65–0.73 under the refined prompt for every model — a ceiling three to seven times higher than periphrasis's best score anywhere in the primary evaluation (never exceeding 0.176 strict). That ordering alone would support a familiar story: easy elements have surface markers, hard elements do not. But antithesis complicates the story, because it also has a locatable surface signal — a pair of lexically opposed terms — and models find that signal readily. The failure is not under-detection but over-claiming: false positives exceed true positives for every model under both prompts (Claude Sonnet 4.6's refined-prompt result, for example, is 6 true positives against 12 false positives), a pattern invisible on the two-poem development set, where antithesis support was a single instance, and only legible once the three-poem test set's 43 instances made it measurable. A model that over-generalizes "two opposed words" into "antithesis" without checking whether the opposition is the point of the line is making a qualitatively different error than one that cannot locate periphrasis at all. An account of this corpus's difficulty pattern that collapses to a single axis — "simple" elements near a ceiling, "complex" elements near a floor — misses this distinction, and with it, the difference between a precision problem and a recall problem calling for different remedies.

The trope subtype breakdown sharpens this further. استعارة فعل (verb-anchored metaphor, trope's largest subtype by volume) moved from 83% missed under the baseline prompt to 62% missed under the refined one — the single largest subtype-level gain the frozen evaluation recorded — because a verb used in a sense that cannot apply literally in context gives the model a locatable incongruity to anchor on, much as simile's particle does, even though locating that incongruity and distinguishing it from ordinary polysemy takes a small inferential step a bare particle does not. استعارة تمثيلية (whole-clause allegory) offers the sharpest illustration that a locatable marker need not be a lexical particle at all: hypothesized as trope's hardest subtype from a two-poem development sample, it proved to be the easiest at test scale (29% missed under the refined prompt, against مجاز مرسل's unmoved 85%), because the figurative reading is typically the only sensible reading for the entire clause — there is no competing literal reading left standing for the model to be tempted by. مجاز مرسل itself is the clearest counter-case: a closed, conventionalized set of substitutions (the sky "raining" when the cloud is the actual agent) with no compositional anomaly to key on, and the one subtype no prompt intervention in this study moved at all, stuck at 85% missed under both baseline and refined prompts. Read together, what predicts a model's success across this corpus is less how conceptually elaborate a figure is held to be in the classical taxonomy, and more whether some feature of the line — a particle, a lexical opposition, or a foreclosed literal reading — gives the model a seam to locate, or leaves the literal and figurative readings standing side by side with nothing to break the tie.

Periphrasis's one partial exception to this pattern deserves to be stated carefully, because the finding is genuinely mixed rather than a straightforward improvement. Allowing a model free-form Arabic reasoning space before answering, rather than a closed-form, no-explanation JSON schema (the two-stage Config C pipeline), produced the largest periphrasis gain found anywhere in this project on one development poem — strict F1 0.111 to 0.316 — and caught a periphrasis instance every structured-pipeline configuration in this study missed for that verse. But a second independent run of the same free-form configuration frequently disagreed with the first about which phrase in the verse deserved the tag, so that most of the instances this configuration could reach at all were caught in only one of two runs; under this project's own two-run-majority convention, applied consistently everywhere else in this study, most of the apparent gain does not survive. The honest statement is that periphrasis is reachable under a different output format, but not yet reliably decidable by any configuration this study tried — a model can sometimes find the right reading when given room to reason, without having a stable criterion for recognizing it as right twice in a row.

## Prompt sensitivity as a finding about LLM-assisted literary analysis, not only a limitation

The subtype-level recall screen surfaces a second pattern that is worth treating as a result in its own right rather than as noise to be apologized for. كناية لغوية (a periphrasis subtype in which an elided noun is identified only by its surviving epithet) is Gemini 3.5 Flash's strongest subtype in that screen (0.719 recall, n=32) and GPT-5.4-mini's near-total failure on the identical lines and prompt (0.031) — and GPT's two runs agree closely with each other at that low figure, so this is a model-specific collapse, not single-run noise. استعارة تمثيلية shows the mirror-image pattern in the same screen: Gemini's weakest subtype (0.143) against GPT's strongest relative performance on it (0.571), consistent across both of GPT's runs. Separately, a one-shot-versus-three-shot comparison run for استعارة تمثيلية specifically found recall moving from 15.4% to 38.5% with two additional worked examples — one of the few subtypes where adding examples helped at all, and a demonstration that a single worked example can anchor a model's reading of a subtype in a way that one additional example can substantially unsettle.

None of this licenses a claim that either subtype is secretly easy for some undiscovered configuration, and this paper does not make that claim. What it does license is a more specific methodological finding: for a non-trivial fraction of this taxonomy's subtypes, which model is queried and how many worked examples anchor its reading of a category can move recall by tens of percentage points on the identical lines — a swing comparable in size to the headline differences this study reports between entire rhetorical elements. For a field accustomed to treating "I asked ChatGPT about this verse" as a single, stable operation, the lesson is that it is not: the result depends on a choice of model and prompt design usually invisible in how the result gets reported. This extends Reimann and Scheffler's (2025) and Fuoli et al.'s (2025) contrasting findings for metaphor detection in other languages — that figurative-language performance depends heavily on how a model is deployed, not only on which model is asked — by showing the same instability subtype-by-subtype, within one evaluation, for a single language and a single annotator's ground truth.

## Cross-model consistency and idiosyncrasy (RQ3)

RQ3 asked whether difficulty patterns are consistent across models or idiosyncratic to each one, and the honest answer, on this evidence, is both, depending on the grain examined. At the level of the four top-level elements, the three primary-evaluation models agree closely: all three show periphrasis as the hardest element and simile as the easiest, and the refined prompt helps trope, simile, and antithesis for every model while leaving periphrasis essentially flat for every model. At the level of individual trope and periphrasis subtypes, however, the two-model cross-model screen shows GPT-5.4-mini scoring strictly lower than Gemini 3.5 Flash on ten of thirteen reliable subtypes and strictly higher on the other three, with the كناية لغوية and استعارة تمثيلية reversals described above as the sharpest examples. This two-grain pattern is broadly consistent with Kühn, Mitrović and Granitzer's (2024) finding that named rhetorical figures beyond metaphor and irony remain a structurally under-studied, inconsistently handled class across languages and systems generally, and with Attia et al.'s (2026) finding that large language models measurably underperform on Arabic figurative language even where human annotators agree closely with each other — both results this study's own element- and subtype-level ordering corroborates for classical Arabic poetry specifically, without depending on either paper's own figures to do so.

## What this means for humanities scholars using LLMs on classical Arabic poetry

Read together with Al Kaabi et al.'s (2024) qualitative finding that ChatGPT produces surface-level readings of Arabic rhetorical figures that miss the depth a trained reader supplies, this study's quantitative results suggest a more specific and more usable version of the same caution. For an element whose definition names an explicit surface marker — simile here, and plausibly tashbīh's close relatives in other classical traditions — a general-purpose LLM's zero-shot output is close enough to a detection task that a scholar can reasonably treat it as a fast first pass, to be checked rather than trusted blindly. For periphrasis, and for the closed, conventionalized subclass مجاز مرسل specifically, this study's evidence points the other way: model output on these categories should be treated as unreliable rather than as a substitute for manual reading, not because the model never finds the right answer, but because it has no demonstrated way of finding it reliably twice. And for the subtypes most exposed to prompt- and model-dependent swings, the practical implication is not that LLMs cannot help with this kind of analysis, but that the specific model and prompt design are themselves part of what a scholar using an LLM this way needs to report, in the same spirit Dobson (2021) urges for any accuracy figure presented as more decisive than its underlying evidence warrants. This paper's own contribution is best read in that diagnostic register: not a claim that large language models have or have not solved classical Arabic rhetorical-element identification, but a characterization of exactly where, and under what conditions, they currently can and cannot be trusted to try — extending, with quantitative evidence, the frontier Abd Alhadi, Hussein and Kuflik (2023) named as beyond their own rule-based system's reach.
