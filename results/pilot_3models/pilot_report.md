## 7. Observations & next steps

- Among elements with enough ground-truth support to compare (n>2): **Simile** is strongest (mean F1=0.64) and **Trope** weakest (mean F1=0.15) — consistent with the pattern found across the rest of the project (see THESIS_KNOWLEDGE.md §4): simile is consistently the easiest element for LLMs, trope/kenning the hardest. Elements excluded from this comparison for low support: Antonymy — see the next bullet.
- Ground-truth support is very small for this one poem: Antonymy (n=1). Scores for these elements (especially any showing F1=1.0) rest on 1-2 positive instances and are not statistically meaningful on their own — this is the single biggest reason to scale the harness to more poems before drawing conclusions.
- **GPT-5.4 mini** found zero true positives for **Trope** (missed all 8 ground-truth instances) — worth a closer look at whether this is a systematic gap for this model/element pair or specific to this poem.
- Mean cross-model agreement across all 4 elements: 89.1%. High agreement on an element mostly reflects all 3 models agreeing on the (common) negative class — genuine agreement on *positive* detections is lower and visible only in the per-verse disagreement list (§5c).
- Instruction-only JSON (no structured-output mode) produced perfectly parseable JSONL from all 3 providers across all 6 runs — zero parse errors. Worth testing whether provider-native structured-output/JSON-schema modes change accuracy (not just formatting reliability) in a follow-up run.
- **Next step**: re-run this exact harness (unchanged code, `python experiments/pilot_3models/run_pilot.py` with `config.POEM_PATH` pointed at a different poem) across the other 4 poems used historically (Al-Nabigha, Jarir, Abu Tammam, Imru' al-Qais Poem 1) to get statistically meaningful per-element numbers and build the standardized evaluation harness flagged as the top-priority gap in ENHANCEMENT_PLAN.md.
